## My Reflection

Before starting these labs, I only had a basic understanding of Artificial Intelligence. While I had come across terms such as Transformers, RAG systems, and AI agents, I had no prior experience building or working with them. Completing these six practical sessions helped me bridge the gap between theoretical concepts and how these models actually operate in practice.

For **Lab 01**, I worked on sentiment analysis using machine learning techniques. Practicing text preprocessing, feature extraction, and model evaluation gave me a clear introduction to Natural Language Processing and demonstrated how raw text data is prepared for analysis.

**Lab 02** was one of the most engaging sessions of the module. Focusing on everyday student challenges showed me how generative AI tools can be used effectively for brainstorming and practical problem-solving rather than just theoretical exercises.

When we progressed to **Lab 03** on Transformer models and text generation, the technical difficulty increased noticeably. Concepts such as tokenization, embeddings, and attention mechanisms were challenging to grasp at first. However, running the sample code and modifying different parameters eventually helped me understand how modern language models generate text.

In **Lab 04**, I explored model fine-tuning using LoRA and QLoRA. I found this session particularly valuable because it demonstrated how existing language models can be adapted for specific tasks without requiring heavy computational resources to train a model from scratch.

**Lab 05** focused on Retrieval-Augmented Generation (RAG). Building a workflow that retrieves relevant information from documents before generating an answer was very insightful, particularly in understanding how AI systems can improve response accuracy using external knowledge sources.

Finally, **Lab 06** brought these concepts together through AI agents and tool integration. Learning how a language model can connect with external tools to perform real tasks, rather than simply generating text, gave me a clearer understanding of how practical AI applications are developed.

One of the main challenges throughout the module was working with new technologies and development tools. I encountered issues such as missing package installations, syntax errors, and file path problems while running programs. I also faced difficulties when creating GitHub repositories, uploading files, organizing project folders, and updating README files correctly. Since GitHub was relatively new to me, I initially made several mistakes while managing my portfolio. However, solving these issues step by step helped me improve my debugging, troubleshooting, and project management skills. It also increased my confidence in working independently with software development tools.

Another valuable experience was learning how to document and organize projects professionally. Maintaining README files, managing repositories, and presenting completed lab work gave me a better understanding of software project documentation and version control practices.

Overall, I gained valuable experience in Natural Language Processing, Transformer models, fine-tuning techniques, Retrieval-Augmented Generation, AI agents, Python programming, and GitHub project management. Most importantly, working with modern AI technologies no longer feels intimidating, and I am more confident in exploring advanced AI concepts in future academic projects. I believe the knowledge and practical experience gained throughout this module will be beneficial for both my future studies and my career in computing.
