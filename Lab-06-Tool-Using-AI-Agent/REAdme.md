# Lab 06 - Building a Tool-Using AI Agent with Ollama

## Objective
To understand how AI agents can use external tools to perform tasks and automate workflows.

## Tasks Completed
- Set up Ollama and LangChain
- Created a calculator tool
- Built a tool-using AI agent
- Tested multiple tool integrations
- Added memory functionality
- Explored RAG-powered AI agents
- Investigated Google Calendar integration
- Explored workflow automation using n8n

## Technologies Used
- Python
- Ollama
- LangChain
- SQLite
- n8n
- Google Calendar API

## Learning Outcomes
This lab provided practical experience in building AI agents that interact with external tools and services. I learned how memory, retrieval systems, and workflow automation can enhance the capabilities of Large Language Models.
