# Lab 05 - RAG Architecture

## Objective
To understand the fundamentals of Retrieval-Augmented Generation (RAG) and build a document-based question-answering system.

## Tasks Completed
- Set up the Python environment
- Installed LangChain and required libraries
- Processed PDF documents
- Generated embeddings for document chunks
- Stored embeddings in ChromaDB
- Implemented a retrieval pipeline
- Integrated an LLM for answering questions
- Tested the system using university-related documents

## Tools and Technologies
- Python
- LangChain
- ChromaDB
- Ollama
- Streamlit
- PyMuPDF
- Sentence Transformers

## Learning Outcomes
This lab provided practical experience in building Retrieval-Augmented Generation applications. I learned how document retrieval, vector databases, embeddings, and Large Language Models work together to answer questions based on external knowledge sources.
