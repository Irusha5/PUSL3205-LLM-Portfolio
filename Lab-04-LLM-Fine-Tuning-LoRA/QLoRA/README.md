# Lab 04 - Fine-Tuning an LLM Using LoRA/QLoRA

## Objective
To understand how Large Language Models can be fine-tuned efficiently using LoRA and QLoRA techniques.

## Tasks Completed
- Installed required libraries
- Checked GPU availability
- Selected an instruction-tuned language model
- Created a custom question-answer dataset
- Configured LoRA settings using PEFT
- Fine-tuned the model
- Compared original and fine-tuned model responses
- Evaluated model performance

## Tools and Libraries
- Python
- Transformers
- Datasets
- PEFT
- TRL
- Accelerate
- Bitsandbytes

## Learning Outcomes
This lab provided practical experience in adapting pre-trained language models for specific domains using parameter-efficient fine-tuning techniques. It also helped develop an understanding of LoRA, QLoRA, and modern LLM training workflows.
